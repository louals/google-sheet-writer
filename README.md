# sheet-writer

> Python tool for writing and manipulating Google Sheets data via the Google Sheets API.

![Status](https://img.shields.io/badge/status-active-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

## Overview

Python tool for writing and manipulating Google Sheets data via the Google Sheets API.

## Tech Stack

Python, Google Sheets API

## Features

- Automates spreadsheet operations
- Programmatic data entry
- Service-account or OAuth authentication

## Getting Started

### Prerequisites

Make sure you have the tools required for this stack installed (e.g. Python 3.10+, Node.js 18+, or Android Studio).

### Installation & Usage

```bash
git clone https://github.com/<your-username>/sheet-writer.git
cd sheet-writer
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt   # if present
python main.py
```
> Replace `main.py` with the project's entry script if different.

## Configuration

Enable the Google Sheets API and place your credentials file in the project root.
